# Bachelor Thesis Workspace

Title: AI-Assisted CI/CD Pipeline Optimization for an Attendance Management System: A Case Study of iSign

This repository contains the thesis planning, analysis scripts, notes, results, and report-working files.

Main thesis case: iSign Attendance Management System

Main folders:
- plan/ - thesis plan, scope, research questions and schedule
- notes/ - work log, literature notes, meeting notes and decisions
- isign_analysis/ - workflow analysis, baseline and data availability
- scripts/ - data collection, preprocessing, statistics, baseline method and Isolation Forest
- data/ - public, processed and sample datasets
- results/ - tables, figures and measurements
- report/ - thesis report working material
- references/ - guidance documents, source notes and project materials
